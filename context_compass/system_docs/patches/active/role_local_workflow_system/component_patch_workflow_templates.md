# Component Patch: Workflow Templates

## Purpose
Define the top-level simple and advanced workflow templates.

## Before/After
Before:
- no dedicated workflow templates

After:
- `workflow_simple_template.md`
- `workflow_advanced_template.md`

## Key Rules
- simple template is the default
- advanced template is optional for higher-stakes or richer workflows
- templates are scaffolding only, not a workflow registry
