# Commands

Purpose
- Explain how command registries work and where to find them.

Registry files
- User registry: `context_compass/commands/commands_user.json`
- System registry: `context_compass/commands/commands_system.json`
- Schema: `context_compass/schemas/command_registry.schema.json`

Generation
- Registries are machine-owned and generated by:
  `python context_compass/tools/command_registry_generate.py --repo-root . --agent-id <agent_id> --work-id <work_id>`

How to use
- Read the user registry to see the user-facing command list.
- Read the system registry for the full agent toolset.
- Commands may still be blocked by feature flags or repo_state.

Notes
- Registries are minified JSON and should not be edited by hand.
