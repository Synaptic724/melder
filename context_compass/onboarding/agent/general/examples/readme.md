# examples

This folder contains golden example artifacts for context_compass.

JSON examples
- *.pretty.json is for human reading only.
- *.min.json must match the canonical minified writer contract.
 - file_ctx and dir_ctx examples model src/melder/utilities/logger.
- repo_state examples show lifecycle assessment and tooling_policy gating.
- architecture_context and component_contexts examples show matrix-based freshness and citations.
- command_registry examples show user/system command registries.
- memory_store examples show user/system memory entry shape.

Python examples
- examples/python/* are canonical style references for docstrings, cleanup, logging, and tests.
- Component and integration test examples live alongside unit patterns.
- Use them as copy-first patterns when editing code.
