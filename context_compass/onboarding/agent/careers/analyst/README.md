# Analyst Career

This folder is reserved for analyst-specific onboarding material that
extends or overrides the shared general career content.

Add only analyst-specific skills, policies, or behavioral guidance here.
Shared defaults live in ../general and are indexed in ../general/SKILLS.md.

Key files
- SKILLS.md: analyst-specific read order
- skills/analysis_execution.md: analyst execution rules
- policies/analysis_quality_policy.md: evidence requirements
- behavioral_guidelines/analysis_workflow.md: execution flow guidance
