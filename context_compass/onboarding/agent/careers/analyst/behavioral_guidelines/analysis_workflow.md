# analysis_workflow

Purpose
- Describe the expected execution flow for analyst tasks.

Story steps
1) Confirm the question and the decision it will drive.
2) Identify the minimal data sources required.
3) Run targeted queries and gather artifacts.
4) Present findings with source references.
5) State recommendations and open questions.
