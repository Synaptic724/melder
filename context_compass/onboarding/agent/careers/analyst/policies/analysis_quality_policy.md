# analysis_quality_policy

Purpose
- Establish the quality bar for analyst outputs.

Policy
- Every claim must be backed by a source or a clearly labeled assumption.
- Provide evidence for conclusions (query output, file paths, or tool results).
- Do not speculate about system state; verify via the approved tools.

Exceptions
- Only allowed with explicit user approval, documented in the response.
