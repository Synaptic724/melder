# Project Manager Career

This folder is reserved for project-manager-specific onboarding material that
extends or overrides the shared general career content.

Add only project-manager-specific skills, policies, or behavioral guidance here.
Shared defaults live in ../general and are indexed in ../general/SKILLS.md.

Key files
- SKILLS.md: project-manager read order
- skills/pm_execution.md: work coordination rules
- policies/pm_quality_policy.md: work queue quality bar
- behavioral_guidelines/pm_workflow.md: execution flow guidance
