# Hard MCQ Answer Key Template (sealed)

Use this template for sealed per-cycle answer-key records.

File naming (recommended)
- `context_compass/skill_check/.sealed/exams/cycle_<cycle_id>_answer_key.json`

ANTI-CHEAT WARNING
- Do not read sealed answer keys before blind submission.

Required fields
- cycle_id
- generated_at_utc
- question_count
- questions[]
  - question_index
  - question_id
  - doc_id
  - source_path
  - source_anchor
  - correct_letter
