# workspace

Purpose
- Scratch pad for user-defined behaviors, experiments, and workspace-specific tooling.
- Reserved for user-owned assets that can become first-class tools later.

Current policy
- Ignore this directory for scanning and automated ingestion (manual only).
- Do not treat contents as canonical system state.

Usage notes
- Keep artifacts self-contained so they can be promoted into supported tools.
- Document assumptions and dependencies inside the workspace item.
