# work_management

Purpose
- Define how work is tracked and executed in this repo.

Policy
- Use `epics/`, `stories/`, and `tasks/` tickets for all planned work.
- Follow `WORKFLOW.md` and `SKILLS.MD`.
- Convert approved scratch notes into tickets; do not leave work in scratch.

Ticket flow
1) Create a ticket from the templates.
2) Confirm scope and acceptance criteria.
3) Execute with small, reviewable changes.
4) Report validation status truthfully.
5) Close only after the user confirms acceptance criteria.
