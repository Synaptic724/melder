# agent_stories

Purpose
- Provide narrative, step-by-step stories for how agents operate in this repo.
- Organize the flows so humans and agents can reason about the system consistently.

Source of truth
- Behavior rules live in `AGENTS.MD` and `agent_onboarding/agent/general/skills/*`.
- These stories are descriptive and must not override policy.

How to use
- Start with `onboarding_summary.md`.
- Then read the story that matches the work you are about to do.

Stories (index)
- `onboarding_summary.md`: concise onboarding checklist and references.
- `agent_lifecycle_and_heartbeat.md`: session lifecycle, check-in/out discipline, and handoff habits.
- `work_intake_and_execution.md`: ticket intake, planning, execution, and closure workflow.
- `task_execution_and_validation.md`: executing tasks, validation discipline, and truthful reporting.
