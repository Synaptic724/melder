# AethericRift Consolidation Workspace

This folder is where we consolidate months of AethericRift ideas into a small set
of coherent, reviewable documents.

## Contract
- These docs are working artifacts, not an approved spec.
- Everything should be tagged as: PROPOSED, DECIDED, or UNKNOWN.
- "DECIDED" only applies after the user explicitly confirms the point.
- Sources are the older idea tickets under `context_compass/artifacts/` (they contain
  drift and contradictions).
