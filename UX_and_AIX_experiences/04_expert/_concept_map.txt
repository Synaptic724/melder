SOURCE FIXES MADE ALONGSIDE THIS TIER (2026-08-03)

  1. THE HUSK BUG IN THE RESET DOORS - MutationResearch, then Crystallizer.
     SYMPTOM: `test_the_host_is_keyword_only` went red with
     `AttributeError: object has no attribute '_cleaned'` raised from
     inside `_reset_singleton_for_tests` itself.
     CAUSE: `__new__` publishes the singleton BEFORE `__init__` runs, and
     a construction that fails on the SIGNATURE (positional `aether`)
     fires its TypeError before `__init__`. `Cleanable.__slots__` is
     `['_cleaned']` and the flag is assigned in `__init__`, so the
     published husk has the slot UNSET - reading it raises rather than
     returning a default. The reset door died on the exact object it
     exists to clear.
     THE TEST HAD ALREADY PREDICTED THIS in its own comment: "a signature
     TypeError fires before `__init__` runs, so the body's rollback never
     executes and `__new__`'s published instance is left installed. The
     class's own reset door is what clears it." The door just could not.
     FOUR DOORS, THREE IMPLEMENTATIONS, WHICH IS HOW IT SURVIVED:
       Nexus            try/except AttributeError/finally - husk-safe
       Crystallizer     `not instance.cleaned`   - LATENT, same hole
       MutationResearch `not instance._cleaned`  - the one that fired
       Aether           try/finally, NO except
     THE REAL FIX WAS SMALLER THAN THE FIRST ATTEMPT (owner ruling):
     DELETE THE LIVENESS CHECK ENTIRELY. Every one of the four
     `cleanup()` methods already guards its own `_cleaned` flag and
     returns early, so a caller-side "is it clean yet" test was pure
     redundancy - and it was the redundancy that crashed, because it read
     a slot a husk does not have. A reset door does not need to know
     whether the thing is live. It cleans and it clears.
     ALL FOUR ARE NOW ONE SHAPE, verified by AST rather than by eye:
       clean unconditionally -> swallow the husk AttributeError ->
       clear `_instance` / `_initialized`
     Aether included: it keeps propagating real cleanup failures (its
     documented contract) and no longer dies on a husk. The "divergence"
     recorded here earlier was not a divergence to preserve - it was
     three copies of the same avoidable check, and the author had added
     a fourth before being told to stop.

THE TIER'S OWN SHAPE, NOW THAT IT IS DONE

  BEFORE any boot at all (18). In between it goes: record what changed
