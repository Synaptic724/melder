# Learn by running examples

The example curriculum lives alongside Melder's source, organized into the same
four levels: Beginner, Intermediate, Advanced, and Expert.

## Your first working graph

[Hello Melder](hello-melder.md) binds one ordinary class, conjures a conduit,
and resolves an instance. The page displays the actual saved script.

## Choose a level

| Level | Focus |
| --- | --- |
| [🟢 Beginner](../beginner/index.md) | First graph, addresses, lifetimes, scopes, cleanup |
| [🟡 Intermediate](../intermediate/index.md) | Configuration and connected subsystems |
| [🟠 Advanced](../advanced/index.md) | Isolated worlds, inspection, precise targeting |
| [🔵 Expert](../expert/index.md) | Agent operations, persistence, research, governed change |

Run saved scripts from a checkout with Melder installed and the supported
free-threaded interpreter selected. Keep accompanying helper files with any
lesson that imports them.
