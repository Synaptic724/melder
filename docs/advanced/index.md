# 🟠 Advanced

**Isolation and inspection: separate worlds, runtime views, and precise targeting.**

Work at wider boundaries while keeping ownership and authority explicit.
A spellframe categorizes objects within a world; an aetheric frame identifies
an isolated world. The distinction matters when a process hosts several systems.

## What you will learn

- Aetheric frames, posture, configuration, and initialization order.
- Deep, wildcard, and broadcast override targeting.
- Clusters and coordinated lifetimes.
- Nexus, Rifts, static rooms, and viewer navigation.
- Visibility, policies, workstation ownership, and continuity entry points.
