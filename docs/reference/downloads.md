# Read offline

Choose the format that fits how you read:

| Format | Contents |
| --- | --- |
| Complete HTML archive | The entire website: all four levels, every saved example, API reference, and drawings |
| PDF handbook | All four guide levels, the glossary, and five selected complete examples, with contents and bookmarks |
| ePub handbook | The same scoped handbook in a reflowable reading format |
| Example collections | Each level's complete Python scripts and local helper modules |

On a hosted version, the Read the Docs download menu lists the formats available
for that version. Pull-request previews may provide HTML only; use a successfully
built public version for its handbook downloads.

[Browse the example collections](../examples/index.md) for individual source and
collection downloads. The handbook links to the full website when a reference or
example falls outside its printed selection.

To produce the files from a checkout, follow [the local build instructions](../maintaining.md).
Always match the document's version label to the package you are using.
